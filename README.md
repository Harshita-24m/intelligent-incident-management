# Intelligent Incident Management & Root-Cause Prediction Platform

A full-stack incident management system for engineering teams, with an
integrated machine learning pipeline for incident category/severity
prediction, root-cause prediction, anomaly detection, and similar-incident
search.

> Status: Under active development (built incrementally, phase by phase)

## Tech Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Backend:** Node.js, Express, TypeScript, Prisma, PostgreSQL
- **ML Service:** Python, FastAPI, scikit-learn
- **Infra:** Docker, RabbitMQ, Redis

Full documentation will be added as the project develops (see `docs/`).
